A free-form sensor panel for the G.Skill WigiDash

Place one widget at 5×4 and it draws a full-screen dashboard from a JSON layout file. It replaces the AIDA64 SensorPanel setup without the WigiDash grid look, and uses the sensor data WigiDash Manager already collects through its bundled HWiNFO. AIDA64 is not needed.

Download the latest release See the skins

How it works

  • A normal widget

    WigiDash Manager loads it like any other widget, so its pages, sleep and brightness behaviour all keep working.

  • Drawn for the device

    Layouts are designed on the physical 1024×600 canvas and shown centred on the 5×4 widget (1016×592). Coordinates from an AIDA64 WigiDash panel carry over unchanged.

  • HWiNFO sensors

    Sensors come from the Manager's own sensor list. Bindings in the layout pick them by regex on name, source and unit.

Native skins

The widget ships with {{SKIN_COUNT}} JSON skins built for it. Each one shows date and time; CPU and GPU name, temperature, clock, power, load, memory and VRAM used vs total; FPS; 12V-2x6 per-pin current; water loop pump, water temperature, fan and flow; and network IPv4/IPv6 with download and upload speed. Select a skin to see it at full size.

Features

  • JSON layouts

    Rectangles, text, bars, ring gauges, graphs and images, with colour thresholds. Text templates mix sensor values, CPU and GPU model, host name, date and time. // comments are allowed.

  • Regex sensor bindings

    Bind a sensor by regex on its name, source and unit. Use the first match, or combine every match with avg, max, min or sum.

  • AIDA64 skin import

    Loads WigiDash LCD skins (.gslcd) and SensorPanel skins (.sensorpanel) directly, including their images, image-strip gauges, labels, values, bars and graphs. AIDA64 doesn't need to be installed.

  • Skin switching

    Pick a skin from the list in the widget's settings, or swipe or long-press the panel on the WigiDash to move to the next one.

  • Per-skin overrides

    An aida-sensors.json next to a skin changes only the sensor mappings it lists, such as a date format that fits the skin's artwork.

  • Custom fonts

    Fonts in a skin's folder or its Fonts subfolder load automatically. Fonts in the widget's fonts folder are available to every skin.

  • Live reload

    The panel reloads when the layout, or anything in its folder, is saved. Double-tap the panel on the device to reload it by hand.

  • Offline preview

    A command-line preview tool renders any layout to a PNG with demo values, so you can iterate without the device.

Install

You need WigiDash Manager. You don't need the .NET SDK.

  1. Download wigidash-panel-X.Y.Z.zip from the latest release and extract it.
  2. In the extracted folder, run: 
    powershell -ExecutionPolicy Bypass -File .\install.ps1
    The script closes WigiDash Manager, copies the widget into place and restarts the Manager.
  3. In WigiDash Manager, add a page and drop Sensor Panel onto it at size 5×4.

To build from source, edit layouts, or see the full layout format, read the README.
